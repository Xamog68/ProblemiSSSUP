# Fonte storica

La fonte integrale del cantiere è:

```text
SA_Libro.zip
SHA-256 14c69d4ee323a3f2a4d5554cb3869f0fc2cbd0c573446be3ab2279246022487b
```

Lo ZIP originario deve essere conservato immutato fuori dal repository Git.
Contiene, oltre ai sorgenti utili, prodotti di compilazione, PDF parziali,
vecchie copie e altri ZIP annidati.

Nel repository sono stati importati soltanto:

- `SA_Book.tex`;
- `SA_Book.sty`;
- i 78 file modulari `SA_YYYY_N.tex`.

Non sono stati importati PDF, DVI, PS, AUX, LOG, file Mathematica, sorgenti
monolitici superati o archivi annidati. La loro eventuale consultazione deve
avvenire nella fonte storica, senza produrre altre copie nel cantiere.
